# Tiny Stack VM

A from-scratch interpreter for make.fun's tiny stack ISA, written in plain
Node.js with no dependencies. It runs all 40 programs in one pass with exact
trap, step-limit and output-limit semantics, and scores 40/40 on the practice set.
